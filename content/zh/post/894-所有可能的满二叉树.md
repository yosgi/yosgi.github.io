用时： 抄答案才做出来

思路很容易看出来是利用递归，但是coding才是真正的问题。

我们需要返回的是根节点，但是递归是从下至上的

尝试用动态规划解决，dp(n) 是 dp(x) 与 dp (n - x - 1) 结果的组合

```javascript
var allPossibleFBT = function (n) {
  if (n % 2 === 0) return [];
  const dp = Array.from({ length: n + 1 }, () => []);
  dp[1] = [new TreeNode(0)];
  for (let size = 3; size <= n; size += 2) {
    for (let left = 1; left < size; left += 2) {
      const right = size - left - 1;
      for (const leftRoot of dp[left]) {
        for (const rightRoot of dp[right]) {
          const node = new TreeNode(0);
          node.left = leftRoot;
          node.right = rightRoot;
          dp[size].push(node);
        }
      }
    }
  }
  return dp[n];
};
```
