## 为什么 DFS 用栈，BFS 用队列？

栈是**后进先出（LIFO）**，队列是**先进先出（FIFO）**。递归 DFS 依赖函数调用栈；写成迭代形式时，可以用显式栈保存尚未访问的节点。BFS 则用队列，先处理当前层，再处理下一层。

DFS 并不都“从下到上”处理。前序在访问左右子树之前处理当前节点，中序在两棵子树之间处理，后序在两棵子树之后处理。访问顺序和处理节点的时机需要分开理解。

## DFS：前序搜索模板

每次弹出栈顶节点并检查它。为了先访问左子树，先把右孩子压栈，再把左孩子压栈。找到目标就返回，否则一直处理到栈为空。这里的模板是前序搜索；中序和后序需要相应调整入栈和处理步骤。

```javascript
function findDepthFirst(root, predicate) {
  if (!root) return null;
  const stack = [root];
  while (stack.length) {
    const node = stack.pop();
    if (predicate(node)) return node;
    if (node.right) stack.push(node.right);
    if (node.left) stack.push(node.left);
  }
  return null;
}
```

## BFS：层序搜索模板

从队首取出节点，把它的孩子加入队尾。用 `head` 下标推进，避免反复 `shift()` 搬动数组元素。这个简化实现会保留已访问的队列槽位，因此队列数组的空间上限是 O(n)。

```javascript
function findBreadthFirst(root, predicate) {
  if (!root) return null;
  const queue = [root];
  for (let head = 0; head < queue.length; head++) {
    const node = queue[head];
    if (predicate(node)) return node;
    if (node.left) queue.push(node.left);
    if (node.right) queue.push(node.right);
  }
  return null;
}
```

例如，`findDepthFirst(root, node => node.val === 7)` 会返回第一个值为 7 的节点；找不到时返回 `null`。对一棵含 n 个节点的二叉树，两种搜索的最坏时间都是 O(n)。以上 DFS 的显式栈空间是 O(h)，h 为树高；BFS 示例保留的队列数组空间是 O(n)。
